**Checked, not guessed:**
- **Contrast:** I computed the full 8×8 matrix with the WCAG luminance formula. 20 fg/bg pairs pass 4.5:1. The nearest values to the threshold are 4.00 (white on red) and 5.25 (red on black), so rounding can't change a result.
- **Row 23 colours:** because white on red fails, the quick links are black text on red, green and yellow, and white text on blue.
- **Mosaic mapping:** bit k is sextant position k+1. 0 maps to space, 21 to U+258C, 42 to U+2590 and 63 to U+2588. Any other value v maps to `U+1FB00 + v − 1 − (v>21) − (v>42)`. I checked all 64 values against the Unicode 15.0 character names: no mismatches, 64 distinct code points.
- **Attribution lines:** I counted each one; all fit in 30 characters.

**Decisions I made where the brief is silent.** These are marked as decisions in the files, and you may want to change some:
- **Character set:** printable ASCII, plus `£ ° €`, plus the Latin-1 letters. Text outside it is converted by one function, and an item that still doesn't fit is skipped, not shown with a substitute character.
- **Blank cells:** a blank cell is always a text space, never an empty mosaic. This keeps the parse/serialise round trip exact.
- **Hand-written pages:** files in `pages/*.page` hold only rows 2–21. Code builds rows 0, 1, 22 and 23.
- **Exact layouts** for rows 0, 1, 22 and 23.
- **Refresh and staleness:** I chose the refresh intervals, and a source counts as stale when its data is older than twice its interval.
- **Number formats** for rates, temperatures and other values.
- **Byte budgets:** these are starting numbers, about 64 KiB for the first load (compressed).
- **Colour-link keys** are Z, X, C and V.

**Left open on purpose:**
