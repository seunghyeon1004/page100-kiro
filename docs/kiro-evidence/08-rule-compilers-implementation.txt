## Where the code won over the design (all recorded in `requirements.md`)
- **Launches:** the source has `rocket` and `mission` but no provider or pad. Page 610 shows the rocket.
- **`city-data.ts`:** requirement 1.2 allows only type imports from `src/sources`, so `p200`, `p201`, `p300` and `p301` could not use `CITIES` and the series symbols. I added copies in `src/compilers/city-data.ts`, and `city-data.test.ts` fails if either side changes alone.

- **`checkDraft`:** it takes a third argument, a row locator, so error messages can name the page row.
